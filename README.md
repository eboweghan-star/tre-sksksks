# tre-sksksks

Admin panel web app for this repository.

## Panel app

The dashboard lives in [`panel/`](panel/). It is a React + TypeScript app built with Vite.

```bash
cd panel
npm install
npm run dev
```

Open the URL Vite prints (typically `http://localhost:5173`).

| Command        | Description              |
|----------------|--------------------------|
| `npm run dev`  | Start dev server         |
| `npm run build`| Production build         |
| `npm run lint` | ESLint                   |

The panel includes a sidebar layout, dashboard metrics, activity feed, and placeholder pages for Analytics, Users, and Settings.
